# AI 模式 · 批次刪除

在 Google AI 模式（`google.com/search?udm=50` / AI 模式頁）的左側「最近的討論串」列表上，
畫出勾選框、支援全選，然後一次把勾起來的討論串通通刪掉。

免費、沒有數量上限、資料不出你的電腦。沒有後端、沒有帳號、沒有 token。

---

## 為什麼要做這個

市面上那類擴充功能把「批次刪除」鎖在付費牆後面（免費只給你刪 5 個），
但說穿了它做的事就是：幫你連續點開每一列的 `⋮` → 刪除 → 確認。
這件事用一個 content script 就能做完，不需要付錢。

---

## 安裝（載入未封裝擴充功能）

1. 把整個 `ai-mode-bulk-delete` 資料夾放到你不會亂刪的地方
2. 打開 Chrome，網址列輸入 `chrome://extensions`
3. 右上角把 **開發人員模式** 打開
4. 左上角按 **載入未封裝項目**，選 `ai-mode-bulk-delete` 這個資料夾
5. 釘選右上角的圖示（可選）

> 每次啟動 Chrome 會跳「請停用開發人員模式擴充功能」的通知，按 **保留** 就好。

安裝完 **重新整理** 已經開著的 Google 頁面，否則 content script 不會注入。

---

## 使用

1. 到 Google AI 模式，把左側「最近的討論串」展開
2. 右邊會出現面板（也可以按工具列圖示開關）
3. 用面板勾、或直接點頁面上每一列左邊新出現的勾選框
4. 按 **刪除選取** → 確認 → 等它跑完

> 頁面上的勾選框會先幫每一列讓出一條左邊走道（只改 `padding-left`），
> 所以框子永遠不會壓到標題文字；把「頁面勾選框」取消勾選就會把間距還原。
> 這跟螢幕解析度或系統縮放比例無關，全部用 `getBoundingClientRect()` 算，是 CSS px。

> **同名討論串**（例如兩個都叫「Browser Harness」）會被當成兩列各自處理：
> 勾選用的是 Google 每一列的 `data-thread-id`，不是標題，
> 所以「全選」的數字會跟列數一致，刪除與匯出也是一列對一列，不會漏掉第二個。

面板上的東西：

| 按鈕 | 作用 |
| --- | --- |
| 全選 / 反選 / 清除 | 選取操作 |
| 重掃 | 手動重新抓一次列表 |
| 校準 | 抓不到清單時，點一下任一個討論串教它認 |
| 診斷 | 把目前抓到的 DOM 資訊複製到剪貼簿（回報問題用） |
| 刪除選取 | 開始批次刪除（跑的時候會變成「停止」） |
| 匯出清單 | 只把勾選的標題存成純文字清單（刪之前想留個紀錄很方便，不會產生 .md） |
| 匯出內容 | 把勾選的討論串「內容」整篇抓下來，存成 純文字 / JSON |
| 載入全部討論串 | 自動往下滾，把延遲載入的舊討論串也撈出來 |

「間隔」是每一筆之間的等待毫秒數。預設 700ms，調快（例如 300）會快很多，
但如果 Google 那邊反應慢，可能會有幾筆失敗，失敗的會留在清單裡讓你重跑。

### 介面語言

面板上的 **語言** 下拉可以切換 **繁體中文 / 简体中文 / English**，
選完會立刻換、也會記住。匯出的檔案標頭、log、對話框都跟著這個設定走。

## 匯出討論串內容

按 **匯出內容** → 選格式 / 範圍 → 開始匯出。

它會一篇一篇「自己點開」，等內容不再變動後，把右邊對話區的文字抓下來，
最後把全部篇數存成一個檔（不是一篇一個檔）。

| 格式 | 輸出樣子 |
| --- | --- |
| 純文字 | 每篇一個【編號】標題，段落之間空一行，標題前後空兩行，項目縮兩格 |
| JSON | `{ threads: [{ title, url, text }] }`，好寫程式處理 |

**來源卡片與旁邊的廣告都不收**：Google 會在回答尾巴掛一排「來源」卡片（favicon + 網站名 + 標題 + 摘要），
右邊那一欄偶爾還有贊助廣告。那些對「只想看結論」的人沒用，所以匯出的檔案裡直接不會出現，只留回答本身。

判斷方式是看「文字是不是幾乎都落在一個外部連結裡」——Google 的來源連結其實是跳轉網址
（`www.google.com/url?q=…`），所以不能看到 google 網域就當成站內連結跳過；
有些版本沒有 `<a>`、只用 `role="link"` 做的卡片也認得出來。
回答**正文裡**的連結不會被誤刪（那段文字扣掉連結以後還有一大段話，就判定是正文）。

輸出的樣子大概長這樣：

```
AI 模式 討論串匯出
匯出時間：2026/11/8 下午 12:13
篇數：3
來源：https://www.google.com/search?udm=50...

──────────────────────────────────────────────

【1】DSH Discord 模型互動接入

是的，DeepSeek Harness (DSH) 有對應的插件...


重點整理

重點一：先把需求拆成幾個小步驟。

──────────────────────────────────────────────
```

**簡體轉繁體**：預設開著。有些人問 AI 模式時自己的問題就是簡體，或回答裡引用了簡體原文，
打開之後整份檔案不會混到簡體字。不需要就把它取消勾選。

幾個要注意的：

- 跑的時候**這個分頁要留在前景**，切到別的視窗會抓不到（瀏覽器會把背景分頁降速）
- 畫面會一直跳，那是它在切換討論串，正常
- 每一篇會等到「真的講完」才收手：文字安靜約 1.2 秒後，**再確認一次**有沒有繼續長，
  還在長就繼續等；所以長回答不會只抓到開頭
- 長回答會先自動捲到底再捲回來，把還沒畫出來的段落逼出來
- 真的等到 40 秒還沒停（例如一直在生成）才會硬收，log 會標 `⚠ 可能不完整` 提醒你那一篇要自己補看
- 長文之後會多留一點緩衝才點下一篇，避免頁面還沒收尾就被打斷
- 連續匯出多篇時，如果某一篇一時切不過去，它會**自己重試一次**（log 會出現 `↻ 重試一次`）
- 抓的是「畫面上看得到的文字」，圖片、圖表、被收合的區塊不會有
- 很長的對話如果 Google 有做延遲載入，可能只抓到已載入的那一段
- 抓錯區塊（例如抓到整頁、或抓到整個側邊欄）就按設定視窗裡的 **內容校準**，
  點一下右邊的對話區，它之後就只抓那一塊

> 找對話區不用先校準：它會從側邊欄右邊多點取樣，取「最大但不含側邊欄」的那個容器，
> 所以 `main`、`#main`、全寬 wrapper 都吃得下。真的抓錯了再用「內容校準」覆蓋。

## 抓不到清單怎麼辦

Google 的 class 名稱是每天在變的，所以這支擴充功能不靠 class，靠的是：

1. 找每一列右邊那顆 `aria-label` 含「更多選項 / More options」的鈕，往上回推整列
2. 找不到就用結構猜（左側、寬度、高度、垂直連續、排除導覽項目）
3. 都不行 → 用你校準的結果

**校準**：按面板的「校準」→ 頁面上方會出現藍色提示 → 用滑鼠點左側任何 **一個** 討論串。

校準會優先記住那一列的 **class**（同一份 DOM 裡每一列都共用），記不到才退回「父層路徑 + 標籤」。
如果記到的東西只認得出 1 列，擴充功能會**自己丟掉**這個校準、改回自動偵測，不會卡在壞掉的狀態。

## 隱私

- 只讀你眼前這個頁面的 DOM，只在你按下去之後才模擬點擊
- 沒有任何 `fetch` 到外部伺服器，沒有分析、沒有遙測
- 設定只存在 `chrome.storage.local`
- 不讀 cookie、不讀 token、不碰你的密碼

---

## 已知限制

- **刪除是真的刪**，Google 沒有 API 可以復原，擴充功能也救不回來
- 匯出內容不含圖片與表格結構，只抓文字
- 匯出的檔案不含「來源」卡片與旁邊的廣告；如果你其實需要那些網址，得自己另外記
- 匯出時會切換討論串，結束後畫面會停在最後抓的那一篇
- 簡轉繁是「單字對照」為主，少數一字多形的字（例如「干」/「乾」）靠常見詞表補，
  罕見用法還是可能挑錯字
- Google 改版就可能失效 → 這時按「診斷」把結果貼出來，改選擇器就好
- 只支援「最近的討論串」那種列表；不處理 Google 帳號裡的「全部活動」
- 需要你自己已登入；擴充功能不會幫你登入
- 不要跟那個付費擴充同時開，兩個都會在頁面上畫勾選框

## 檔案結構

```
manifest.json          MV3 設定
content/content.js     全部邏輯（偵測、勾選框、刪除引擎、匯出、面板）
content/i18n.js        介面三語字串
content/s2t.js         簡→繁 對照表（OpenCC STCharacters 精簡版）
popup/                 工具列彈出視窗
icons/                 圖示
test/run-test.js       端到端測試（真的開 Chrome 跑）
test/aimode/fixture.html  測試用的假 AI 模式頁面
test/shot.js           截圖用
test/make-icons.py     重新產生圖示
test/build-s2t.js      重新產生簡繁對照表
```

## 開發

```bash
node test/run-test.js   # 用 headless Chrome 跑完整流程（載入 → 校準 → 單刪 → 批次刪）
node test/shot.js       # 產生 preview.png
py test/make-icons.py   # 重畫圖示
```

測試會把擴充功能複製到暫存資料夾、把 match 改成 `http://127.0.0.1/*`，
再用 CDP 的 `Extensions.loadUnpacked` 載入（`--load-extension` 在 headless 不可靠）。
